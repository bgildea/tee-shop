# tee-shop

Print-on-demand T-shirt shop for Thailand. Static site on Netlify, English and Thai, no stock held.

Working name: Tee Shop (placeholder, set in one config file so it is easy to rename).

## Status

Pre-launch. Not selling yet, no domain. Designs and order flow still being worked out.

## Planned layout

- `public/` static site (HTML, CSS, JS, art, print files, mockups)
- `netlify/functions/` order email and PromptPay QR functions
- `tools/` scripts to render chest proofs (Playwright) and 300 dpi print PNGs (rsvg-convert)
- `docs/` brief and decisions

See `docs/brief.md` for the full project brief.
